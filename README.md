# ME Mix — Site

Site da ME Mix Serviços de Bombeamento de Concreto.

- Bombeamento de concreto com bomba lança (32, 36 e 43 metros) e bomba estacionária
- Atendimento em toda a Grande São Paulo, das 07:00 às 19:00
- Instagram: @memixbombasdeconcreto

O `index.html` é a prévia real aprovada, com o sistema de pré-orçamento e o botão de WhatsApp.

Domínio `.com.br` a definir pelo cliente; site e domínio ficam no nome dele.
